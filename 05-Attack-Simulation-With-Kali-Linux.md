# Attack Simulation With Kali Linux
---
## **<ins>Section Objective:</ins>**

  In this section, Kali Linux will be used with Crowbar, which is a brute-forcing tool that targets remote access services like RDP (Remote Desktop Protocol). A real-world attack against the lab was confirmed when it surfaced in Splunk, proving the detection pipeline works. 

  This centers on why strong passwords matter. Crowbar rapidly tries many password combinations until one works, succeeding through weak or reused credentials rather than sophisticated hacking. A SIEM can detect the attack, but a strong password is what stops it, which is why teaching users about length, complexity, and uniqueness, and enforcing it through policy, is a frontline defense. This simulation makes that risk visible and measurable.
